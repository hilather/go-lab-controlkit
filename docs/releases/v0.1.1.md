# go-lab-controlkit v0.1.1

Release date: 2026-10-26
Previous release: [v0.1.0](v0.1.0.md)

## Highlights

Patch after v0.1.0. No API or behavior change in any package.

- CI and release `GO_VERSION` move from 1.26.9 to 1.26.10 for GO-2026-6809 (crypto/x509), and the README CI pin follows. `go.mod` stays `go 1.26` with no toolchain line.
- Release docs: the v0.1.0 notes' tag line no longer has pre-tag text, and they no longer say there is no GitHub Release (Helm published one by hand). The `v0.1.0` tag and its GitHub Release body keep the old wording; no retag.
- SECURITY.md names `v0.1.0` as the supported minor; unreleased `main` is no longer supported.
- README status and option ledger updated (v0.1.0 tagged, hand-published Release; dns v1.6.0 refuses tokens shorter than 32 bytes).
- The fuzz-smoke script comment names go1.26.10.

## Compatibility

Source compatible with v0.1.0. Consumers need no change.

## Release gate

Tag only on a green CI run of the tag push. `release.yml` requires this file and a `## v0.1.1` line in `CHANGELOG.md`.
